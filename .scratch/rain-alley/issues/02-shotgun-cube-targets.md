# 02 霰弹方块靶

## What to build

在白盒雨巷里，玩家用唯一的泵动手感霰弹打方块靶：左键开火、R 整匣换弹、8 发弹匣、备弹无限。命中是一簇即时散射（约 8 粒、无飞行时间），门口距离一枪能打掉普通靶，半巷距离明显掉伤害。白盒阶段就要有枪口焰、弹壳、火星和枪声，让每一枪读得出来。本票证明「一句话一具尸体」的霰弹幻想和换弹脆弱窗，不接真实敌人 AI。

## Blocked by

01 Studio白盒雨巷

## Status

ready-for-agent

## Acceptance checklist

- [ ] 玩家能用左键打出泵动手感霰弹（低射速、非半自动连喷），弹匣 8 发、备弹无限
- [ ] R 换弹约 2.5–2.8 秒期间只能走不能跑、不能开火，弹匣打空后必须换完才能再打
- [ ] 门口距离一枪清掉普通方块靶；走到巷中段再打，同一靶明显更难一枪清
- [ ] 开火时能看见/听见枪口焰、弹壳、火星、枪声；连射不会把画面卡成「每枪重建整个世界」
- [ ] v1 只有这一把玩家武器；闲置/收起的枪不跟着每帧相机或骨骼根乱甩
- [ ] 本票可单独演示：走进巷、打近靶、打远靶、空仓换弹再打
- [ ] 只改 `rain-alley`；Hellforge 零改；不 push
