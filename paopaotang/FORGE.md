# 泡泡糖 (paopaotang)

一个泡泡堂 / Crazy-Arcade 式的糖果竞技场小游戏。

## 玩法
- **WASD / 方向键** 移动,**空格** 在脚下放一颗会膨胀的泡泡(引信 2.5s)
- 泡泡爆开成 **十字水花**:炸开软糖方块、连锁引爆其他泡泡、消灭果冻怪
- 软糖方块 35% 掉落道具:💥 范围 +1 / 🫧 泡泡 +1 / 👟 速度提升
- 自己的泡泡在你离开那格后就变成障碍 —— 别把自己困住哦~
- 清空全部 4 只果冻怪 → 胜利;被水花波及或被怪碰到 → 失败;**R** 重开一局

## 结构
- `assets/scene.pack.json` — 静态竞技场:13×13 地面、边界墙、5×5 硬柱阵、Player 盒子人、阳光/天空(✎ Edit 与 ▶ Play 同源)
- `main.ts` — 动态层:相机、输入、网格移动、PCG 软方块与敌人、泡泡/水花/道具(瞬态实体)、胜负与重开
- `src/hud.ts` — DOM HUD:泡泡数 / 范围 / 速度 / 得分 / 剩余敌人 + 胜负横幅 + 道具 toast
