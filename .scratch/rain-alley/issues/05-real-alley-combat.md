# 05 真实巷战

## What to build

雨巷变成真打：5 个手枪马仔探头射击，玩家很脆（约 3 发就会死），霰弹门口一枪一个、半巷掉伤害。转角必须安全到能换弹。清掉 5 人后厨门解锁，走进厨房是物理过门不是硬切。敌人用简单 hitscan，不另做一套枪系统。本票只交付巷战这一段的可玩纵向，不接刀手和大衣。
