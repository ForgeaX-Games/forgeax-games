# 泡泡糖 · Onboarding

> 一句话:**不做教程关,做"被地图和反馈教会"的第一局**。玩家从头就在玩真实对局,只是前 30 秒的地图和道具经过特调,把三条柱按顺序喂出来。

## 三个里程碑(这一刻第一次解锁了什么)

- **30s — 微循环闭环解锁**:玩家已经完成过一次「放泡 → 撤离 → 十字爆 → 炸碎方块 → 得分」。这一刻他会的是柱1 的正面(拆墙),还没体会到风险。
- **60s — 变强动机解锁(柱3)**:玩家踩到第一个道具(保底 🔥),看到 HUD 火力跳字 + 下一颗爆炸变长,建立"炸方块=变强"的因果。滚雪球的欲望在此点燃。
- **180s — 风险闭环 + 攻防解锁(柱1 反面 + 柱2)**:玩家要么用泡泡把敌人堵死完成第一次封锁击杀(柱2),要么因火力变大误判被自己/连锁炸死看到「按 R 重来」。无论哪条,他都学到了"变强=更容易困住自己",风险管理这根柱子第一次真正生效。

## 教学动机链(为什么玩家会主动做,而不是被命令)

教学不写"按空格放泡泡";写玩家**为什么想放**。

| 阶段 | 玩家的内在动机(不是指令) | 我们如何用环境勾出这个动机 |
|---|---|---|
| 想移动 | "我控制的是谁?这只脚下在发光,试试" | 出生角色脚下呼吸光圈 + 一条"方向键移动"提示(唯一一次给按键) |
| 想放泡泡 | "前面这堵软方块挡路,能不能弄开" | 出生 L 形安全区正前方**必放一片软方块墙**,靠近时方块冒"空格键放泡泡"气泡 |
| 想撤离 | "泡泡在搏动、还放大闪了,它要炸,我得躲" | 引信搏动 + 爆前 0.4s 膨胀预警,靠视觉本能触发后退,不写"快跑" |
| 想炸更多 | "炸一下就通了路、还加分,爽" | 第一次十字爆脆响 + 得分跳字 + 露出新路径,正反馈驱动连炸 |
| 想吃道具 | "碎方块里叮地弹出个发光东西,想要" | onboarding 特调:出生区旁那片软方块**保底掉 🔥**(正式局回归 25% 随机) |
| 想封锁敌人 | "它比我慢,好像能把它逼到角落" | 敌人初始移速 3.4 < 玩家 4.0,残局前 AI 不提速,给玩家一个"我能追上它"的窗口体会围堵 |

## 教学地图特调(仅第一局 / 教学开关开启时)

正式对局用 balance.md 的随机布局;新手第一局做以下微调,让节拍表能踩准:

1. **保底软方块墙**:出生 L 形安全区正前方放一排 3 格软方块,保证玩家第一次放泡有明确目标。
2. **保底掉宝**:上述墙里指定 1 格软方块必掉 🔥(而非 25% 随机),确保 60s 前一定吃到第一个道具。
3. **前 45 秒 AI 不主动逼近**:敌人在自己象限游走,给玩家学放泡/撤离/吃道具的安静窗口;45s 后恢复正常 AI 权重开始施压。
4. **残局提速延后**:教学局把残局阈值临时降到 <20%(而非 30%),避免新手还没学会走位就被提速的 AI 打爆。
5. 教学开关:元进度里记录"是否完成过首局",完成后关闭上述所有特调,回归纯随机。

## 节拍密度自检(第一分钟每 5–8s 必须有一次系统反馈)

| 秒 | 系统反馈存在? | 反馈内容 |
|---|---|---|
| 0–2 | ✅ | 棋盘弹开 + BGM 进 |
| 4–8 | ✅ | 脚步声 + 撞墙钝响回弹 |
| 8–10 | ✅ | 软方块冒"放泡泡"气泡 |
| 10–14 | ✅ | 泡泡弹出搏动 + 膨胀预警闪 |
| 14–15 | ✅ | 十字爆脆响 + 方块碎 + 得分跳字 |
| 25–30 | ✅ | 道具叮地弹出 |
| 30–40 | ✅ | 踩🔥 火力跳字 + 下颗爆炸变长 |
| 40–45 | ✅ | 差点自炸的预警惊险帧 |

密度达标,无空场。若实装后玩家反馈"前 30 秒发闷",回到本表找哪 5–8s 的格空了,补一个微反馈(音效/抖动/跳字),不要靠加文字。

## 失败即教学(风险闭环的收尾)

第一次死亡不是惩罚,是最后一课:死亡定格 0.6s 让玩家看清"我是被自己那颗变长的泡泡炸的"——把柱1 反面(变强=更危险)钉进记忆。「按 R 重来」晚 0.5s 浮现,给一口"我懂了,再来"的气,直接把回流欲望接上 loop.md 的"差一步被反杀"长期钩子。
