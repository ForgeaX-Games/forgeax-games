# chapter_mx 影游媒体

把万灵糖境影游主片 / 私密特写 / DM 立绘放到这里。

约定文件名（与 `src/narrative/content/scripts/chapter_mx.ts` 中 `assets` 字段对齐）：

| 文件 | 用途 |
|---|---|
| `mx_open_master.webp`（或 `.webm`） | 开场主片 |
| `mx_open_private_0.webp` … `_3.webp` | 四人私密特写 |
| `mx_n2_master.webp` … | 关间影游 |
| `mx_finale_master.webp` | 终章 |
| `dm_katrina.webp` | DM 卡特里娜糖 |

Demo 可暂缺文件；Director 会按脚本时长空跑，并在控制台提示 missing。
