# 泡泡糖 · MVP 玩法规格

目标:落地 5–60s 微循环 + 单局。1 张 13×11 地图、玩家 vs 3 敌人、三种道具、引信/十字爆炸/连锁/封锁全通。

## 颗粒 1 · 放泡泡 → 引信 → 十字爆炸

**规则**
- 玩家按放置键,在其所在格中心生成一颗泡泡(受当前泡泡上限约束)。
- 泡泡为实体障碍(玩家离开该格后,再回来无法穿过)。
- 引信 2.5s;爆炸前 0.4s 泡泡视觉放大闪烁。
- 爆炸沿十字四向各延伸 = 当前火力(格),遇硬墙截断,遇软方块炸掉该块后截断(不穿透),遇其他泡泡触发连锁引爆。
- 水花停留 0.5s;停留期内命中的玩家/敌人死亡。

**验收命令**
- 打开 `http://127.0.0.1:18920/preview/?game=paopaotang`
- 放一颗泡泡,站在原地不动 → 2.5s 后应被自己水花炸死(证明引信+自伤生效)。
- 放一颗后立刻走开 ≥2 格 → 存活,且十字方向的软方块被炸碎(证明范围+方块摧毁)。
- 两颗泡泡相邻放置 → 先炸的引爆后一颗(证明连锁)。

## 颗粒 2 · 道具掉落与增益

**规则**
- 炸碎软方块时 25% 概率在原格生成道具(火力/泡泡/鞋子,各 1/3)。
- 玩家走上道具格即拾取,按 balance.md 上限累加。
- 未拾取的道具被后续水花波及则销毁。

**验收命令**
- 炸开一片方块直到掉出火力道具 → 拾取后再放泡泡,十字明显变长 1 格。
- 拾取鞋子 → 同距离撤离耗时肉眼变短。

## 颗粒 3 · 敌人 AI 与胜负

**规则**
- 开局生成 3 只敌人于对角出生点。
- AI 每 0.6s 重规划:优先躲开将爆炸的水花范围,其次向玩家逼近,再次炸方块开路。
- 敌人靠近玩家 2 格内 60% 概率放泡泡(放前校验自身有撤离路径)。
- 被任意水花命中的敌人死亡。全灭敌人 = 胜利;玩家死亡 = 失败。
- 软方块 <30% 时,AI 决策节拍 0.6s→0.4s、移速 +0.4(残局提速)。

**验收命令**
- 用泡泡把一只敌人封进死角(堵住唯一出口)→ 引信到 → 该敌人死亡计数 -1。
- 全灭 3 敌 → 出现胜利结算;站在自己水花里 → 出现失败结算。
- 场上软方块降到 <30% → 观察到敌人明显变快(可在 console 打印节拍值佐证)。
