# 04 完整三段白盒FSM

## What to build

玩家能走过完整切片骨架：开场闪回拍 → 雨巷 → 茶餐厅厨房（单过道两门口）→ 大厅（长方形宴席、两侧转角、远端正门）→ 大衣对峙 → 胜利闪回。白盒几何三段都在；门在「本段击杀达标」后自动解锁，走进即切段，无 E 键。死亡只重开当前段（大衣出场后死不重打六个厅枪）。本票可用占位击杀/清场条件走通状态机，不要求真实三种 AI。

ready-for-agent

## Acceptance checklist

- [ ] 玩家能按顺序经历：开场闪回拍 → 巷 → 厨 → 厅 → 大衣对峙 → 胜利闪回（闪回可以是占位画面，但段顺序不能跳）
- [ ] 巷是下雨 L 形窄巷+转角；厨是单过道两门口；厅是长方形宴席+两侧转角+远端正门；无支路
- [ ] 本段清场后对应门自动解锁，走进才切段；没有互动键开门
- [ ] 玩家在某一段死亡后只从该段重来，不重放更早的段；大衣对峙死亡不重打厅内六个枪手当成一段
- [ ] 不能从巷跳进厅、不能跳过大衣对峙直接胜利
- [ ] 本票可单独演示：用占位清场走完整条线，再故意死在厨/厅验证重开点
- [ ] 只改 `rain-alley`；Hellforge 零改；不 push
