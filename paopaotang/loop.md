# 泡泡糖 · 三层 Loop

## 5–60 秒 · 单次交锋(主导:柱1 引信博弈 + 柱2 空间封锁)

`放泡泡 → 撤离到安全格 → 引信到、十字水花炸开 → 炸碎软方块/困住敌人 → 掉道具`

- 一个完整微循环 ≈ 2.5s 引信 + 走位,约 3~5 秒。
- 每一次放泡泡都是一次"我撤得掉吗 / 我堵得死它吗"的博弈决策。
- 反馈瞬时:方块碎、得分跳、道具掉、敌人死。

## 30 分钟 · 单局对战(主导:柱3 增益滚雪球)

`清场开局(方块密) → 炸方块吃道具变强 → 火力/泡泡数上涨、场地变空 → 残局贴身封锁 → 活到最后 / 全灭敌人`

- 一局(单张地图)目标时长 **90~180 秒**;一次游玩坐下来打 8~12 局 ≈ 30 分钟。
- 前期(方块多)=资源期,靠柱3 滚雪球;后期(场地空)=对峙期,靠柱1/柱2 走位定胜负。
- 阶段转折点:场上软方块 <30% 时,进入"残局",敌人 AI 提速(见 balance.md AI 节奏)。

## 1 周 · 长期驱动(主导:元进度,跨局)

`打局 → 累计胜场/连胜 → 解锁新地图布局 & 新敌人类型 → 难度台阶上升 → 追求更高连胜/更快通关`

- 元进度靠三样:**地图数**(布局变化)、**敌人类型**(AI 行为差异)、**难度台阶**(敌人数量/提速阈值)。
- "为什么第二天还回来"的答案:上一局差一步被反杀的残局手感(映射柱1/柱2),以及"这张新地图的道具节奏没摸透"(映射柱3)。
- 首个可交付里程碑:1 张地图 + 1 种敌人 + 完整 5–60s 微循环跑通,即验证三柱成立。
